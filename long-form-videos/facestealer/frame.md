# Design direction

An investigative control room built around one disturbing idea: the face in the
call is evidence. Real source pages sit inside deep, dimensional browser frames.
The camera repeatedly pushes through a webcam rectangle into the next victim,
turning the social-engineering loop into the film's visual grammar.

The focal element is always one of four things: a face window, a source headline,
a single number, or the cursor approaching a dangerous control. Edge anchors use
source labels, chapter counters, and a thin progress rail. Supporting detail is
limited to timestamps, verification marks, and restrained network paths. The
background uses a dark blue-black field with faint grid lines and slow cyan bloom.

No neon hacker silhouettes, code rain, crypto coins, hooded stock photos, glass
cards, or decorative dashboards. Red is reserved for danger, compromise, and
correction. Cyan marks verified evidence.
